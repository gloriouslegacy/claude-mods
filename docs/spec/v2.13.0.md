## F1 qhud 0.21.0 — 사람 입력만 재개를 취소
- 재개·백업을 취소하고 `dropped` 에 넣는 프롬프트는 출처(`origin.kind`)가 `composer`·`bridge`·`sdk` 이거나 출처가 없는 경우만이다.
- 그 밖의 출처(`task-notification`·`scheduled-trigger`·`plugin`·`unclassified`·`peer`·`channel` 등, 엔진에 새로 생기는 출처 포함)는 재개를 취소하지 않는다. 알려진 한계: 엔진이 출처를 못 가리는 사람 입력(`unclassified`·`peer`)은 재개를 막지 못한다.
- 판정은 `hooks/resume.ts` 순수 함수로 둔다. `register.tsx` 는 호출만 한다.
- 재현 테스트: 알림과 함께 재개가 예약된 상태에서 `task-notification` 출처 프롬프트 2건을 보낸 뒤 시계를 리셋+60초로 진행하면 `RESUME_PROMPT` 가 1회 제출된다. 수정 전 FAIL, 수정 후 PASS. `scheduled-trigger` 도 같은 형태로 테스트한다. 기존 `composer`·출처 없음·`sdk` 취소 테스트는 그대로 PASS 해야 한다.

## F2 qhud 0.21.0 — 취소되면 알림
- F1 의 사람 입력이 실제로 걸려 있던 재개(또는 백업)를 취소했을 때만 아래 둘을 한다. 걸린 재개가 없으면 아무것도 하지 않는다.
  - 토스트(영문): 취소된 재개 시각을 담는다. 예: `Auto-resume at 05:11 cancelled (prompt sent)`.
  - 그 프롬프트의 메인 맥락(`prompt.submit` 이 붙이는 context, 알림과 같은 경로)에 한 줄을 붙인다. 예: `[qhud] Auto-resume at 05:11 was cancelled because a prompt was sent; it will not resume automatically for this reset.` 알림 문구와 같은 프롬프트에 함께 붙을 수 있다.
- 메인(`agentId` 없음)에만 붙인다. 문구는 `hooks/resume.ts` 순수 함수로 둔다.
- `autoResume` 끔으로 인한 취소는 이 알림 대상이 아니다.
- 테스트: 재개가 걸린 상태에서 `composer` 프롬프트 → 토스트 1개 + context 에 취소 문구. 재개가 없을 때 `composer` 프롬프트 → 둘 다 없음. `task-notification` 프롬프트 → 둘 다 없음.

## F3 qhud 0.21.0 — 알림 문구가 실제 동작과 맞게
- 자동 이어하기가 켜졌을 때 알림 끝 문구(`resume.ts` 의 `Auto-resume is on: if the limit runs out, …`)를 v2.12.1 F1 동작대로 바꾼다. 알림을 받고 멈춰도 리셋 시각 뒤 자동으로 이어간다는 점이 분명해야 한다. 예: `Auto-resume is on: this session resumes automatically after the limit resets (05:10), even if you stop now; leave notes so the next turn can continue.`
- v2.12.1 명세의 "알림 문구는 바꾸지 않는다"는 이 F 로 대체한다.
- 테스트: 기존 문구 검사 테스트를 새 문구로 맞춘다.

## F4 qhud 0.21.0 — 예약된 재개를 상태 줄에 표시
- 사용자 결정(2026-11-18): 재개(첫 타이머 `resumer`)가 걸려 있는 동안 사용량 줄(한도 줄) 맨 끝에 ` | ↻ HH:MM` 을 붙인다. 시각은 걸린 재개 시각(로컬 시각, 알림 문구의 `clockText` 와 같은 형식).
  - 예: `100% (5d 20h) | 93% (4h42m) | 52% (5d 20h) | ↻ 05:11`
- 예약이 없으면(아직 안 걸림·울림·취소·`autoResume` 끔) 아무것도 붙이지 않는다. 백업 타이머만 남은 상태는 표시하지 않는다.
- 어느 창 때문인지는 표시하지 않는다. 한도 줄이 없는 layout 이면 표시하지 않는다(별도 줄을 만들지 않는다).
- 조각 문구는 `view.ts`/`weather.ts` 쪽 순수 함수, 렌더는 기존 경로(`draw.tsx`). `register.tsx` 는 재개 시각을 뷰에 넘기는 연결만 한다(atom `resume` 또는 뷰 값).
- 테스트: 재개가 걸리면 한도 줄 끝에 `↻ HH:MM`, 취소·발화 뒤에는 없음, 한도 줄 없는 layout 은 없음.
