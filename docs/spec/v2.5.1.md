# v2.5.1 명세 — 띠 버튼 다시 누르면 pane 닫기

사용자 제안 2026-11-08: "sub diff 한번더 클릭하면 닫는게 어떨까?" (v2.5.0 F1 은 다시 눌러도 닫지 않았음.)

## F1. 띠 버튼 토글 (agent-flow 0.8.1)
- 띠의 `[sub_Diff]`·`[main_Diff]`·`[+]` 를 누를 때, pane 이 지금 보이고(`$.ui.panes()` 의 isShown) pane 이 **그 버튼이 여는 화면 그대로**면 `$.ui.close({ id: PANE })` 로 pane 을 닫는다.
  - `[sub_Diff]`/`[main_Diff]`: view 가 diffs 모드이고 선택된 에이전트가 그 행.
  - `[+]`: view 가 flow 모드이고 그 행이 펼쳐져 있음. 닫을 때 행 펼침 상태는 그대로 둔다.
- 그 밖(pane 닫힘·안 그려짐·다른 행/다른 화면)이면 v2.5.0 F1 그대로 연다/바꾼다. 사용자가 손으로 닫은 뒤 누르면 다시 연다.
- close 실패(hook deny 등)는 삼킨다. pane 안 버튼 동작은 바꾸지 않는다.
- 테스트(band-buttons.test.tsx): 같은 `[sub_Diff]` 두 번 → open 후 close 호출; 다른 서브의 `[sub_Diff]` → close 없이 전환; `[+]` 두 번 → close; pane 을 닫은 상태에서 누르면 다시 open.
