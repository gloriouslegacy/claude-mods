# v2.7.0 명세 — 새 플러그인 qcompact (압축 버튼)

배경: effortless(HeyCubit, MIT)의 Compact 버튼 아이디어만 참고. 그쪽은 호스트 내장 `/compact` 를 `$.command.run({ command: 'compact' })` 로 부른다. 코드는 복사하지 않고 새로 쓴다(Haiku 요약 `compactWith` 는 가져오지 않음).

## F1. qcompact 0.1.0 — 입력창 위 [Compact] 버튼 (2026-11-13 사용자 결정)
- 입력창 위 띠(`AbovePrompt`)에 버튼을 **항상** 그린다(호스트 설문이 띠를 차지한 동안만 양보 — pinboard 와 같음). 컨텍스트 문턱·`userConfig` 없음.
- 두 번 눌러 확인: 첫 클릭 → 라벨이 `[Compact?]` 로 바뀜. 5초 안에 다시 누르면 실행, 5초가 지나면 `[Compact]` 로 되돌아감(다시 처음부터).
- 실행: `$.command.run({ command: 'compact' })` — 호스트 내장 압축. 모델을 직접 부르지 않는다. 턴이 도는 중이면 호스트가 유휴가 될 때까지 기다린다.
- 실행 중 라벨 `[Compacting…]`, 이 동안 클릭은 무시. 끝나면 `[Compact]`. 실패(reject)는 `$.ui.toast` 로 알리고 `[Compact]` 로 복귀.
- 슬래시 명령·`$.store` 없음(세션 atom 만). 사용자 화면 문구는 영문.
- 테스트: 확인 상태 전이 순수 함수(대기 → 확인 → 실행, 5초 만료 → 대기, 실행 중 클릭 무시)를 `tests/qcompact.test.tsx` 로 검증. `claude plugin validate ./qcompact`·`claude plugin test ./qcompact` 통과.
