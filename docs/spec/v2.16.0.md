# v2.16.0 명세 — 서브에이전트 시작·완료 시각 표시 (agent-flow)

배경: 2026-11-24 사용자가 agent-flow 띠에서 서브에이전트의 시작·완료 시각을 보고 싶다고 요청. 행 데이터 `AgentRow` 에 `startedAt`·`endedAt?` 가 이미 있다.
사용자 결정(2026-11-24): 띠·pane·`/aflow text` 모두, 형식 `HH:MM–HH:MM`, 경과 시간 뒤에 붙임, 설정 없이 항상 표시. 화면 변경이라 minor(agent-flow 0.13.0, 번들 v2.16.0).

## F1 agent-flow 0.13.0 — 서브에이전트 행의 시각 범위
- 서브에이전트 행(main 행 제외)의 경과 시간 바로 뒤에 시각 범위를 붙인다. 예: `implementer "Move qhud tests off line layout" Opus 5.5 2m00s 14:02–14:04 60.7k tok ×32 ✎13 [sub_Diff] [+]`.
- 시각은 로컬 시간대 24시간제 `HH:MM`(두 자리 0 채움). 구분자는 en dash `–`(U+2013), 앞뒤 공백 없음.
- 실행 중(끝 시각 없음)인 행은 `14:02–` 처럼 시작 시각과 `–` 만.
- 시각 범위 조각은 경과 시간과 같은 색·흐림 처리를 따른다(새 색 없음).
- 같은 문구를 띠(`AbovePrompt`)·pane·`/aflow text` 세 곳 모두 같은 함수로 만든다. 문구·형식 계산은 순수 모듈(`hooks/flow.ts`), 렌더는 `hooks/view.tsx`.
- `startedAt`·`endedAt` 이 벽시계(epoch ms)가 아니면 구현하지 말고 보고한다.
- 실행 기록 `$.store` `log` 형식·`/aflow stats` 는 바꾸지 않는다.
- 테스트: 새 파일 `agent-flow/tests/times.test.tsx`(기존 `agent-flow.test.tsx` 는 500줄 상한 근처). 끝난 행 `HH:MM–HH:MM`, 실행 중 행 `HH:MM–`, 한 자리 시·분의 0 채움, 자정 넘김(`23:58–00:03`), 띠·pane·text 에 같은 글자가 보이는지. 기존 테스트 기대값이 행 문구를 통째로 비교하면 새 문구로 맞춘다. 전체 `claude plugin test ./agent-flow` PASS.
