# v2.4.0 기능명세

결정: 2026-11-08 사용자 인터뷰 — agent-flow 의 왼쪽 pane 자동 열기를 기본 끄고, 프롬프트 위 띠(`AbovePrompt`)에 pin 메모 줄처럼 접힌 한 줄 요약을 기본으로 띄운다. agent-flow 0.6.1 → 0.7.0(`userConfig` 키 추가·기본값 변경·화면 추가 → minor), 묶음 v2.4.0. `/aflow` pane·실행 기록·`$.store`·pinboard 는 바꾸지 않는다.

## F0. 분할 (구현 전, 동작 변경 없음)
- 2026-11-08 사용자 결정: 화면 렌더를 순수 렌더 모듈 `agent-flow/hooks/view.tsx` 로 옮긴다(baseline 3항 예외). register.tsx 466 → 330 이하. 실행 기록 항목 구성은 `stats.ts`, `newRow` 는 `flow.ts`, Change 구성은 `diff.ts` 로.
- 완료 기준: `agent-flow/tests/agent-flow.test.tsx` 를 바꾸지 않고 `claude plugin test ./agent-flow` 통과, 공개 진입점(`register`·`/aflow`·userConfig·atom 키·`$.store` `log` 형식) 불변.

## F1. 설정
- `agent-flow/.claude-plugin/plugin.json` `userConfig`:
  - `autoOpen` 의 `default` 를 **false** 로(키 이름·의미 유지). README 에 "기본값 변경" 으로 적는다(이미 값을 저장한 사용자는 그대로).
  - `band` 추가: boolean, `title` `Show the flow above the prompt`, 기본 **true**. 끄면 띠를 그리지 않는다(`/aflow` pane 은 그대로).
  - `showFlow` 추가: boolean, `title` `Show the flow unfolded at start`, 기본 **false** = 접힌 채 시작.
- 시작 접힘은 pinboard `showBoard` 와 같은 규칙: 프로세스당 첫 `session.start` 에서만 `showFlow !== true` 면 접힘. resume·compact·clear 의 `session.start` 는 사용자가 고른 상태 유지. 세션 atom 전용(`$.store` 에 쓰지 않음).

## F2. 띠 (AbovePrompt)
- 이번 세션에 서브에이전트가 하나도 없으면 띠를 그리지 않고 `next(e)` 를 그대로 돌려준다. `hasSurvey` 때도 양보.
- 머리줄: pane 머리줄과 같은 요약(`Agent flow · main + N agents · R running · W waiting`) + 버튼 `[Show]`/`[Hide]`(접힘 토글).
- 펼침: main·서브 각 **1줄** 트리 행 = pane 의 접힌 행 그대로(✎N·지금 하는 일·⚠ 경고 포함, 2026-11-08 사용자 결정)에서 `[+]`·`[sub_Diff]`·`[main_Diff]` 버튼만 뺀다. view.tsx 의 `mainRow`·`agentRow` 를 버튼 없이 재사용. `[+]` 상세·`main_Diff`/`sub_Diff` 는 띠에 그리지 않는다(pane 전용). 너비는 `e.props.bodyColumns`, 넘치면 truncate.
- 배치: 우리 줄을 위에, `next(e)` 결과(다른 mod 의 줄)를 아래에. pin 메모 줄 위에 오는지는 호스트의 모듈 순서에 달렸다 — 수동 확인 항목(보장 못 하면 보고).
- 틱: 기존 2초 틱 조건에 "띠가 펼쳐져 보일 때" 를 더한다. 접힌 머리줄은 이벤트(spawn·turn·tool)로만 갱신.
