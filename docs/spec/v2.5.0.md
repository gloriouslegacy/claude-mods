# v2.5.0 명세 — agent-flow 띠 버튼·줄 순서

사용자 결정 2026-11-08(스크린샷 보고: 띠를 펼치면 `[+]`·`sub_Diff` 가 안 보임, 띠가 Pins 줄 아래에 옴).
v2.4.0 F2 의 "띠에 버튼 없음"을 F1 이 대체한다.

## F1. 띠 펼침 행의 버튼 (agent-flow 0.8.0)
- 띠를 `[Show]` 로 펼쳤을 때 main·서브 행에 pane 과 같은 버튼을 보인다: `[+]`, 서브 행 `[sub_Diff]`, main 행 `[main_Diff]`(pane 에서 보이는 조건과 같을 때만).
- 버튼을 누르면 띠는 그대로 1줄씩이고 상세·diff 는 띠에 그리지 않는다. 대신 `/aflow` pane 을 열고(이미 열려 있으면 앞으로) 그 행의 해당 항목(`[+]` 상세 또는 그 diff)을 펼친 상태로 보여 준다.
- pane 을 못 열면(호스트 거부 등) 실패는 삼키고 토스트 1회. 띠는 계속 그린다.
- 틱 조건·접힘 동작은 v2.4.0 그대로.
- 테스트: 가짜 호스트로 띠 펼침 → 버튼이 보임, `[+]`/`[sub_Diff]` 클릭 → pane 열기 호출 + 그 행 펼침 상태. 새 테스트는 별도 파일(`agent-flow.test.tsx` 469줄, 상한 500).

## F2. 줄 순서: Agent flow 띠를 Pins 줄 위로
- 목표: 프롬프트 위에서 agent-flow 띠가 pinboard 의 Pins 줄보다 위.
- 조사 결과(deep-reasoner, 엔진 타입 2.1.319): 같은 tier 안의 플러그인 순서를 정하는 옵션은 없다. 목록 앞쪽 플러그인이 바깥(줄이 위). 지금 순서 qhud·pinboard·agent-flow 는 marketplace·installed_plugins.json·settings 가 모두 같아 무엇이 순서를 정하는지 구분 못 함.
- 결정(사용자 2026-11-08): `.claude-plugin/marketplace.json` 에서 agent-flow 를 pinboard 앞으로만 옮긴다. 코드 변경 없음. 보장 없음 — 이미 설치한 환경은 순서가 안 바뀔 수 있다(재설치 필요 여부 미확인). 대안(pinboard 가 Pins 를 `next(e)` 아래로)은 채택하지 않음.
