# v2.10.0 명세 — 프롬프트 위 줄에서 플러그인 이름 빼기

배경: v2.9.0 화면(2026-11-15)에서 `[Compact]` 줄은 플러그인 이름 없이 버튼만 있다. 사용자 제안: `Pins`·`AFlow` 줄도 이름(타이틀)을 뺀다. 줄은 색(노랑·자홍·청록)으로 구분된다. 사용자 결정(2026-11-15): Pins 는 숫자에 단위를 붙이는 꼴, AFlow 는 프롬프트 위 띠에서만 뺀다.

## F1 pinboard 0.8.0 — 보드 머리줄
- `header()` 의 `Pins N` 을 `N pins` 로 바꾼다. N 이 1 이면 `1 pin`. 나머지 꼴은 그대로 — `2 pins (done 1)`·`0 pins · » 20`·`1 pin · » 3`. `[Show]`/`[Hide]`·색·동작 그대로.
- 범위 밖: Claude 에 보내는 문구·`/pin` 결과 문구·`HELP`·`» #N` 표식 줄.
- 머리 주석 예시·테스트 기대값을 맞춘다.

## F2 agent-flow 0.12.0 — 띠 헤드라인
- 프롬프트 위 띠(`bandView`)의 헤드라인에서 `AFlow · ` 를 뺀다 — `main + 2 agents · 1 running · 0 waiting [Show]`. magenta bold·버튼·동작 그대로.
- `/aflow` pane 과 `/aflow text` 는 `AFlow · main + …` 를 유지한다(무슨 화면인지 보여 줌).
- 머리 주석 예시·테스트 기대값을 맞춘다.
