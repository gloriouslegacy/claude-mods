# v2.15.0 명세 — `qhud.layout` 값 `line` 제거 (qhud)

배경: v2.14.0 에서 `compact`(같은 한 줄을 `PromptHint` 에 색 있게, `⚠ qhud:` 접두 없이)를 더한 뒤 `line`(호스트 `$.ui.status`, 단색·접두)은 `compact` 보다 나은 점이 없다.
사용자 결정(2026-11-24): `line` 을 제거한다. 저장된 `line` 은 `compact` 로 옮기지 않고 기본값 `bottom` 으로 떨어뜨린다(매핑 없음). 버전은 minor(qhud 0.23.0, 번들 v2.15.0).

## F1 qhud 0.23.0 — `line` 제거
- `qhud/.claude-plugin/plugin.json` 의 `userConfig.layout.options` 에서 `line` 을 빼고 `description` 에서 `line` 설명을 지운다. `compact` 설명은 `line` 을 참조하지 않는 문장으로 바꾼다(예: `compact: one coloured line under the prompt`). 기본값 `bottom` 과 나머지 값은 그대로.
- `hooks/options.ts`: `Options.layout` 타입과 허용값에서 `line` 을 뺀다. 입력 `'line'` 은 다른 모르는 값처럼 `bottom` 으로 정규화된다.
- `hooks/register.tsx`: `$.ui.status` 로 그리는 경로(`line` 분기)를 없앤다. qhud 는 `$.ui.status` 를 더 쓰지 않는다. `oneLine` 은 `compact` 가 쓰므로 남긴다.
- 버전: `qhud/.claude-plugin/plugin.json` 과 `.claude-plugin/marketplace.json` 의 qhud 항목을 함께 0.23.0 으로.
- 테스트: `parseOptions` 에 `layout: 'line'` 을 주면 `bottom` 이 되는 행을 더한다. 전체 `claude plugin test ./qhud` PASS.

## F2 테스트를 `line` 에서 옮기기 (F1 전에, 동작 변경 없음)
- `qhud/tests/*.test.tsx` 에서 `layout: 'line'` 을 쓰는 테스트를 `compact`(내용 검사가 필요한 것) 또는 표시와 무관하면 그대로 둘 수 있는 다른 값으로 옮긴다.
- `line` 테스트가 검사하던 내용(카운트다운·effort·fallback 표시, Fable 주간 창, `↻ HH:MM` 재개 표시 등)은 `compact` 한 줄(`PromptHint`)에서 같은 글자로 검사해 커버리지를 유지한다. `ui.status` 값을 읽어 내용을 검사하는 테스트는 남기지 않는다.
- 현재 코드에서 전체 `claude plugin test ./qhud` PASS.

## F3 문서
- `README.md`·`README.ko.md`: `line` 설명과 설정 표의 `line` 값을 지우고, 한 줄이 필요하면 `compact` 를 쓰라고 적는다.
- `CHANGELOG.md` 맨 위 `## v2.15.0 (2026-11-24)`: `Removed: qhud.layout value line` — 저장된 `line` 은 `bottom` 으로 돌아가니 한 줄을 원하면 `/config` 에서 `compact` 를 고르라고 분명히 적는다. 설정 키 이름은 바뀌지 않음. Plugins 줄은 qhud 0.23.0 + 나머지 현재 버전.
- `VERSION` 2.15.0.
- F4 반영: README 예시 줄의 `CT 67%` 를 `67%` 로, context 조각 설명이 `CT` 를 말하면 고친다. CHANGELOG 에 `Changed: the context piece shows only the percentage (no CT label) in every layout` 취지 한 줄.

## F4 context 조각의 `CT` 글자 제거 (모든 layout)
사용자 결정(2026-11-24): `band`·`bottom`·`compact` 모두에서 context 조각 앞 `CT ` 를 뺀다. 기호로 바꾸지 않는다.
- `hooks/view.ts` `ctxBlock` 은 `CT 67%` 대신 `67%`(값 없음은 `-%`)를 낸다. `hooks/draw.tsx` 의 `CT ` 라벨 노드를 없애고 퍼센트 조각의 색·스파크라인 등 나머지 표시는 그대로.
- 줄 조각의 순서·구분자는 그대로(`model  |  git  |  67%  |  limits`).
- 예시 주석(`view.ts`·`register.tsx` 머리)도 `CT` 없이 맞춘다.
- 테스트: 기존 `CT` 기대값을 `CT` 없는 글자로 바꾸고 전체 `claude plugin test ./qhud` PASS.
