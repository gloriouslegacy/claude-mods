# v2.0.0 기능명세

결정: 2026-10-31 사용자 인터뷰(change-tutor 바로 완전 삭제 · 기존 설치자는 문서로 수동 제거 안내). 묶음 v2.0.0 (플러그인 제거 → major).

## F1. change-tutor 플러그인 제거
- `change-tutor/` 폴더 전체를 지운다(`git rm -r`).
- `.claude-plugin/marketplace.json`: `change-tutor` 항목 삭제, 설명 문구를 `Three Claude Code mods: qhud, pinboard, agent-flow` 로.
- 설치기: `scripts/install.sh` `ALL_PLUGINS`, `scripts/install.ps1` `$KnownPlugins`·도움말 문구에서 `change-tutor` 를 빼고, 기존 은퇴 목록 `RETIRED`·`$RetiredPlugins` 에 더한다(설치돼 있으면 수동 uninstall 명령만 안내 — 기존 blast-radius·replay-theater 와 같은 방식, 자동 uninstall 없음).
- `scripts/check.sh` `copies`: change-tutor 쪽 3쌍(`diff.ts`·`shortPath`·`Hunk`)을 지우고 `model.ts` 1쌍만 남긴다.
- agent-flow: `hooks/diff.ts`·`hooks/flow.ts`·`types/index.d.ts` 는 이제 복사본이 아니다. 머리 주석의 `shared with change-tutor` 같은 문구만 고치고 로직은 건드리지 않는다. agent-flow 0.6.0 → 0.6.1(patch, `plugin.json`·`marketplace.json` 함께).
- 완료: `bash scripts/check.sh` 통과, `grep -rIi tutor --exclude-dir=.git .` 결과가 CHANGELOG 과거 절·`docs/spec/v2.0.0.md`·migration 문서만.

## F2. 기존 설치자 안내
- 새 문서 `docs/migration/REMOVE_CHANGE_TUTOR.md`(영문 또는 기존 migration 문서와 같은 언어): 제거 이유 한 줄, `claude plugin uninstall change-tutor@my-mods` 수동 제거 명령, 저장된 학습 노트(최근 100건)는 제거 시 사라진다는 경고.
- 격리 실험 결과(2026-10-31, claude 2.1.316): marketplace update 는 성공하지만 설치된 change-tutor 는 자동 제거되지 않고 `plugin list` 에 `failed to load — Plugin change-tutor not found in marketplace my-mods` 로 남는다. `plugin update` 는 exit 1. `claude plugin uninstall change-tutor@my-mods --scope user` 로 깨끗이 제거된다. migration 문서에 이 증상과 명령을 적는다.
