# v2.8.0 명세 — qcompact 0.2.0 (버튼 색·아이콘, 보안 보강)

## F1. qcompact 보안 낮음 4건 보강 (v2.7.0 보안 검토 보류분)
- `register.tsx` `logFailure`: `err.message` 읽기를 try 안으로(던지는 getter 대비).
- 클릭·압축 처리의 catch 안 `$.ui.toast` 를 try 로 감싸 삼킨다 — 토스트가 던져도 phase 는 idle 로 돌아간다.
- `confirm.ts` `cleanReason`: LRM·RLM·ALM(U+200E·U+200F·U+061C)과 폭 없는·서식 문자(U+200B–U+200D·U+2060·U+FEFF)도 공백으로 바꾼다(기존 bidi 처리와 같음).
- `cleanReason`: `Array.from` 전에 문자열을 먼저 자른다(`LIMIT * 2` 코드 유닛). 한도 근처 입력의 결과는 지금과 같다.
- 순수 모듈 쪽 변경은 테스트를 더한다. 새 입출력·설정·진입점 없음.
- (보안 검토 낮음 후속) 치환·trim 전에 먼저 자른다(앞쪽 trim 몫 여유를 두고 결과 동일), 문자 클래스에 `\p{Cf}`·U+FE00–FE0F 를 더한다(엔진 지원 확인), `register.tsx` 의 `expiry?.cancel()` 을 try 안으로 — 던져도 phase 가 `running` 에 남지 않는다.
