# v2.14.0 명세 — 색 있는 한 줄 레이아웃 `compact` (qhud)

배경: 사용자가 2026-11-24 `qhud.layout` = `line` 으로 바꾸자 줄 전체가 호박색 단색이 되고 `⚠ qhud:` 접두가 붙었다. deep-reasoner 분석 결과 버그가 아니라 설계된 동작이다. `line` 은 글자만 받는 `$.ui.status`(`register.tsx` 59, `view.ts` `oneLine`)로 그리고, 접두와 색은 호스트가 입힌다(엔진 타입 `status: (text: string | undefined) => void`, 스타일 인자 없음).
사용자 결정(2026-11-24): `line` 은 그대로 두고 색 있는 한 줄 레이아웃 값을 새로 더한다(minor).

## F1 qhud 0.22.0 — `layout` = `compact`
- `userConfig.layout` 의 `options` 에 `compact` 를 더한다. 기존 값(`band`·`bottom`·`line`)과 기본값(`bottom`)은 바꾸지 않는다.
- `compact` 는 `line` 과 같은 내용·순서(`oneLine` 이 잇는 조각 전부)를 **한 줄**로, `bottom` 과 같은 위치(`PromptHint`, 프롬프트 아래)에 그린다. `$.ui.status` 는 쓰지 않으므로 `⚠ qhud:` 접두가 붙지 않는다.
- 색은 `band`·`bottom` 의 같은 조각과 같게 입힌다(같은 조각은 같은 색). 구분자는 `line` 과 같은 문자열이고 흐린 색(`band`·`bottom` 의 구분자와 같은 처리)으로 그린다.
- 줄이 터미널보다 길면 호스트의 줄바꿈에 맡긴다(잘라내지 않는다).
- `compact` 일 때 `AbovePrompt` 와 `$.ui.status` 에는 아무것도 그리지 않는다(이중 표시 없음). 다른 값에서 `compact` 로, `compact` 에서 다른 값으로 바뀌어도 이전 표면이 남지 않는다.
- 렌더는 `draw.tsx`, 조각·색 판정은 순수 모듈(`view.ts`·`draw.tsx` 기존 경로)에 두고 `register.tsx` 는 layout 분기 연결만 한다.
- `plugin.json` 의 layout `description` 에 `compact: the same as line, but coloured and without the ⚠ prefix` 취지의 영문 설명을 더한다.
- 테스트: `compact` 용 한 줄 렌더 함수가 `oneLine` 과 같은 글자(색 제거 시)를 내고, 조각마다 `bottom` 과 같은 색을 갖는지 검사한다. 기존 테스트는 그대로 PASS.
