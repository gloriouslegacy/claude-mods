# v2.3.0 기능명세

결정: 2026-11-05 사용자 인터뷰 — 보드 시작 상태를 설정으로 고르게 하고 기본은 접힘(Hide), 메모를 추가해도 사용자가 Show 하지 않으면 접힘 유지. pinboard 0.5.0 → 0.6.0(`userConfig` 키 추가·화면 기본 동작 변경 → minor), 묶음 v2.3.0. `/pin` 문법·전달·기록·`$.store` 는 바꾸지 않는다.

## F1. 설정 `showBoard`
- `pinboard/.claude-plugin/plugin.json` `userConfig` 에 `showBoard` 추가: `type` boolean, `title` `Show the board at start`, `description` 은 "끄면(기본) 세션이 접힌 보드(머리줄만)로 시작하고 `[Show]` 나 `/pin` 으로 펼친다"는 뜻의 영문 한 문장, `default` **false**.
- 세션 시작 접힘 상태 = `showBoard` 가 `true` 가 아니면 접힘(`options.showBoard !== true` → folded). 기존 `deliver`·`capture` 처럼 register 시점의 옵션을 읽는다.
- **프로세스당 첫 `session.start` 에서만 적용**(2026-11-05 사용자 결정). `session.start` 는 resume·compact·clear 뒤에도 다시 오므로(v1.4.0 조사) register 범위 변수로 1회만 처리하고, 그 뒤에는 사용자가 고른 Show/Hide 를 유지한다.

## F2. 메모 추가 때 자동 펼침 제거
- `/pin <note>` 로 메모를 추가해도 접힘 상태를 바꾸지 않는다(현재 `add` 의 `folded → false` 제거). 펼침·접힘은 `[Show]`/`[Hide]` 버튼과 `/pin`(접기 토글)으로만 바뀐다. `showBoard` 값과 무관하게 같다.
- 머리줄(`📌 Pins N · » M [Show]`)은 접혀도 그대로 보인다(현행).
