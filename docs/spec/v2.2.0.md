# v2.2.0 기능명세

결정: 2026-11-03 사용자 인터뷰 — 작업 중뿐 아니라 대기 중 입력도 기록(설정 추가 없이 항상), 대기·작업 중 구분 없이 같은 모양, 보드는 첫 줄만 두고 줄마다 펼쳐 보기 추가, 디버그 로그 수정(구 v2.1.1)은 이 릴리스에 묶음. pinboard 0.4.0 → 0.5.0(화면·`userConfig` 제목 변경 → minor), 묶음 v2.2.0. `/pin` 문법·전달 동작·`$.store` 는 바꾸지 않는다. v2.1.0 명세(`docs/spec/v2.1.0.md`)의 F1·F4 를 아래로 대체하고 나머지(F2 세션 한정·20개, F3 키, F5 표식·이동)는 그대로.

## F1. 기록 대상 — 대기 중 입력 포함
- `prompt.submit` 에서 `origin.kind === 'composer'`, `command` 없음, `isMeta` 없음인 프롬프트를 기록한다. **`turnId` 조건을 없앤다** — 대기 중 Enter 도 턴 도중 Enter 도 기록. 명령·알림·피어·플러그인 제출(pinboard 자신의 전달 포함)·서브에이전트 턴은 계속 제외.
- 프롬프트 불변(v2.1.0 F1 그대로): `next(e)` 결과를 그대로 돌려주고 기록은 try/catch 부수 효과.
- 대기·작업 중을 보드에서 구분하지 않는다(같은 흐린 `»` 줄, 같은 번호 체계, 같은 표식·클릭 이동).

## F2. 설정 제목
- 키 `capture`·기본 `true` 는 그대로(사용자 값 유지). `title` 만 `List what you type`, `description` 은 대기 중 입력도 포함한다는 문장으로 바꾼다.

## F3. 펼쳐 보기
- 기록할 때 정리된 전문도 보관한다: 줄마다 제어·서식 문자 치환(v2.1.0 규칙과 같음), 빈 줄 끝 정리, **최대 20줄 × 줄당 200자**(가정 — 넘으면 자르고 끝에 `…`). 세션 atom 에만 둔다(`$.store` 금지).
- 보드는 평소 첫 줄만 그린다(현행). 전문이 첫 줄보다 길면(두 줄 이상이거나 첫 줄이 잘렸으면) 그 줄에 펼치기 버튼(`[+]`, 펼친 뒤 `[-]`)을 그린다. 누르면 그 줄 아래에 나머지 줄을 흐리게 그린다. 여러 줄을 동시에 펼칠 수 있다. 펼침 상태도 세션 atom.
- 글자 클릭 → 이동, `[×]` → 삭제는 그대로. `/pin` 접기는 펼친 줄도 함께 숨긴다.

## F4. 디버그 로그 (구현 완료)
- 표식 성공 로그 제거, 실패만 `$.ui.log`. 호스트가 플러그인 이름을 붙이므로 메시지에 `pinboard:` 접두어를 넣지 않는다.

## F5. 문서·버전
- `README.md`·`README.ko.md`(기록 범위·펼치기·설정 제목), `pinboard/CLAUDE.md`, `HELP` 문구에 기록 설명이 있으면 함께. CHANGELOG `## v2.2.0`(구 v2.1.1 절 흡수), `VERSION` 2.2.0, 두 json 의 pinboard 0.5.0.
